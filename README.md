# homebrew-tap

Homebrew formulae for [junnam586](https://github.com/junnam586)'s projects.

```sh
brew install junnam586/tap/goguma
```

The formulae here are generated by [GoReleaser](https://goreleaser.com) when a
project is tagged, so edit the project's `.goreleaser.yaml` rather than the
files in this repository — anything changed here is overwritten on the next
release.

## Formulae

- **[goguma](https://github.com/junnam586/goguma)** — wakes your Mac for
  scheduled jobs, then lets it sleep again.

  Installing the formula puts the command line tools in place but does not start
  anything. Run `goguma install` afterwards to set up the background services;
  it explains which steps need your password and why, and `goguma install
  --dry-run` shows the plan without touching anything.
